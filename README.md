# SVG Preview

Preview tools for **Lottie** animation files (`.json` / `.lottie`).

## Files

| File | Description |
|------|-------------|
| **`lottie-preview.html`** | Full preview studio — open button, drag & drop, auto-load, PNG export (`P`), WebM recording (`V`) |
| **`Demo.html`** | Standalone demo with embedded animation JSON — opens and plays immediately |
| **`Demos_Template.html`** | Blank template — paste your own Lottie JSON where `animationData = null` is |

## Usage

Open any `.html` file in a browser. For `lottie-preview.html`, click **Open Animation File** or drag a `.json` / `.lottie` file onto the page.

### Controls (lottie-preview.html)

| Key | Action |
|-----|--------|
| `P` | Export transparent PNG |
| `V` | Record 3s WebM video loop |
